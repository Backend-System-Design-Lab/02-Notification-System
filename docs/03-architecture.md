## 4. 요청 흐름

### 정상 흐름

1. 클라이언트가 요청한다.
2. API 서버가 요청을 검증한다.
3. 필요한 데이터를 조회하거나 저장한다.
4. 처리 결과를 반환한다.

### 실패 흐름

1. 실패가 발생할 수 있는 지점을 작성한다.
2. 재시도 여부를 작성한다.
3. 사용자에게 반환할 결과를 작성한다.
